# Capability Matrix

This is the authoritative record of what is real versus planned.

Each Notes cell is a summary of at most 600 characters
(`tests/test_capability_matrix_size.py`). The full record of what is
implemented, how it was proved and what remains unverified is in
`docs/CAPABILITY_DETAILS.md`, linked from the row. A capability change updates
its row, its details section when it has one, and `docs/releases/unreleased.md`;
there is no running changelog here (`docs/releases/capability-history.md` holds
the old one).
