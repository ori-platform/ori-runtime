## Trust anchor: SUBSTITUTED

Signed with an ephemeral development Ed25519 key, substituted in **both**
anchors — `ori/installer/release-keys.json` and the bootstrap's embedded
`PUBLIC_KEY_B64`/`PUBLIC_KEY_SHA256` — **before** the bundle was built. The
signed artifact was never modified afterwards. The one post-signing
substitution is the bootstrap's `download()`, because the real one enforces the
`https://github.com` origin.

This proves nothing about KMS custody, GitHub delivery, redirect enforcement,
published asset completeness, or publication reverification. Those remain the
purpose of a signed `v2.4.0-rc.1` through the protected workflow.
